# before skills

Agent skills from [before.click](https://before.click) — the App Store design gallery.

## Install

```bash
npx skills add alexszczurek/before-skills
```

## Skills

### aso

Write, audit, or improve an iOS App Store listing — app name, subtitle, keyword field, screenshots, preview video, ratings strategy, and localization. Distilled from [our ASO guide](https://before.click/insights/app-store-seo) and fact-checked against Apple's 2025–2026 documentation.

```bash
npx skills add alexszczurek/before-skills --skill aso
```

Once installed, ask your agent to audit your App Store listing, or invoke it directly with `/aso`.
